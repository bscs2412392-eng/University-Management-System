# 🎓 International Enterprise University Management System

A full-stack, enterprise-grade academic administrative portal built with **PHP, MySQL, HTML5, CSS3, and JavaScript**. Designed to streamline university operations with strict data integrity, relational database architecture, and granular Role-Based Access Control (RBAC).

---

## ✨ Key Features

* 🔐 **Granular Role-Based Access Control (RBAC):** Custom action-verb permission models executing directly from MySQL tables for multi-level user roles (**Admin, Faculty, and Students**).
* 🗄️ **Normalized Relational Database:** High-performance MySQL schema managing complex relationships across departments, courses, enrollments, attendance, and grading.
* ⚙️ **Unified Backend Architecture:** Centralized database connection (`db.php`), server-side data validation, and secure CRUD operations.
* 📊 **Administrative & Academic Dashboards:** Clean, responsive user interfaces tailored for rapid record management and operational reporting.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend:** PHP
* **Database:** MySQL (phpMyAdmin)
* **Local Server Environment:** XAMPP / Apache
